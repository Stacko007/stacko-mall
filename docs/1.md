# stacko-mall商城
stacko-mall是一个基于SpringBoot+MyBatis+MySQL的商城项目，基于SpringBoot开发，使用MyBatis作为持久层框架，使用MySQL作为数据库，使用Redis作为缓存，使用Maven进行项目构建。


domain → 无依赖
application → 依赖 domain
infra → 依赖 domain
interfaces → 依赖 application（+ domain）
starter → 依赖 infra + application + interfaces（提供自动配置）


mvn clean package -pl stacko-mall-bootstrap -am -DskipTests && java -jar stacko-mall-bootstrap/target/stacko-mall-bootstrap.jar 


TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: stacko-mall" \
  -d '{"username":"stacko001","password":"123456","tenantId":"stacko-mall","withRefresh":true}' \
  | sed -E 's/.*"token":"([^"]+)".*/\1/')

echo "TOKEN=$TOKEN"
